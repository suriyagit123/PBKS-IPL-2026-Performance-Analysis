# PBKS-IPL-2026-Performance-Analysis
Data-driven performance analysis of Punjab Kings in IPL 2026 using Python, Pandas, MySQL, SQL, and an interactive dashboard.
# DATA-DRIVEN PERFORMANCE ANALYSIS OF PUNJAB KINGS (PBKS) IN IPL 2026

## Project Overview

This project analyzes the performance of Punjab Kings (PBKS) during IPL 2026 using a data-driven approach.

The project combines match-level, batting, and bowling data to study PBKS performance throughout the tournament.

The main analytical story focuses on three phases:

**Strong Start → Losing Streak → Recovery**

The project uses Python and Pandas for data cleaning and analysis, MySQL and SQL for relational data storage and analysis, and an interactive dashboard for visualization.

---

## Research Question

> What factors contributed to the variation in Punjab Kings' performance during IPL 2026?

---

## Project Objective

The objective of this project is to analyze Punjab Kings' IPL 2026 performance by examining:

- Match results
- Team scoring performance
- Opponent scoring performance
- Run difference
- Batting performance
- Batting strike rate
- Bowling wickets
- Bowling economy
- Phase-wise performance
- Match-by-match trends

The analysis is descriptive and identifies patterns and associations observed in the data.
